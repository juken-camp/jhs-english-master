1. be動詞

be動詞が文の中心となり、主語の正体・状態・場所を表す文。
主語 + be動詞 + 〜.　（A＝B）
〜だ／〜だった
主語 + be動詞 + 場所　（存在）
（〜に）いる・ある／いた・あった

例I am happy.（私は幸せです） / I am in Okinawa.（私は沖縄にいます）

使い分け

主語現在過去
Iamwas
I・you 以外の単数iswas
you または複数arewere

否定文・疑問文

形作り方
主語 + be動詞 + not + 〜.be動詞のうしろに not を置く
Be動詞 + 主語 + 〜?be動詞を主語の前に出す
Is he 〜?Yes, he is. / No, he isn't.
Was he 〜?Yes, he was. / No, he wasn't.

2. 一般動詞

be動詞以外の動詞。否定文・疑問文で do / does / did を使う。
主語 + 動詞 + 〜.
〜する

例I play soccer every day.（私は毎日サッカーをします）

主語が3人称単数で現在の文のとき、動詞は語尾に (e)s がつく三単現形になる。

過去の肯定文

主語 + 動詞の過去形 + 〜.
〜した

規則動詞は語尾に -ed（play → played）、不規則動詞は形が変わる（go → went）。過去形は主語によって変わらない。

動詞のつづりの変え方

作る形ふつう注意する語尾例外・重要例
三単現形-s
play → plays		s / x / ch / sh / o → -es
子音字＋y → -ies		have → has
do → does
過去形-ed
play → played		e → -d／子音字＋y → -ied
短母音＋子音字 → 子音字を重ねて-ed		不規則変化は1語ずつ覚える
stop → stopped
ing形-ing
play → playing		語尾のeを取る
短母音＋子音字 → 子音字を重ねる		make → making
run → running

否定文・疑問文

形作り方
主語 + don't［doesn't / didn't］ + 動詞の原形 + 〜.動詞の前に置き、動詞は原形にする
Do［Does / Did］ + 主語 + 動詞の原形 + 〜?主語の前に置き、動詞は原形にする

Does he plays? → Does he play? / Did you went? → Did you go?（does / did のうしろは原形）

3. 文型5文型

動詞と、そのうしろに続く語で文型が決まる。5文型の全体像を見て、SVC・SVOO・SVOCの代表的な形を覚える。

名称・記号並び見分け方例文
第1文型　SV主語＋動詞目的語なし（自動詞）I run.
第2文型　SVC主語＋動詞＋補語主語＝補語You are happy.（You＝happy）
第3文型　SVO主語＋動詞＋目的語目的語あり（他動詞）I play tennis.（I≠tennis）
第4文型　SVOO主語＋動詞＋人＋もの目的語が2つ・人≠ものI give him a book.（him≠a book）
第5文型　SVOC主語＋動詞＋目的語＋補語目的語＝補語We call him Ken.（him＝Ken）

S＝主語、V＝動詞、O＝目的語（「何を・だれを［に］」に当たる語）、C＝補語。

動詞の種類目的語代表例文型の例
自動詞とらないgo / come / arrive / liveHe goes to school. → SV
※to school は前置詞句
他動詞とるlike / use / visitHe visits Kyoto. → SVO

He visited to Kyoto. → He visited Kyoto.（visit は他動詞なので、目的語の前に to を置かない）

第2文型 SVC　補語をとる動詞

形意味形意味
be + 形容詞［名詞］〜だbecome + 形容詞［名詞］〜になる
look + 形容詞〜に見えるsound + 形容詞〜に聞こえる
feel + 形容詞〜と感じるget + 形容詞〜になる

例You look happy.（You＝happy）

You look happily. → You look happy.（SVCの補語には副詞ではなく形容詞を置く）

第4文型 SVOO　目的語を2つとる動詞

形意味形意味
give + 人 + もの人にものを与えるshow + 人 + もの人にものを見せる
tell + 人 + もの人にものを伝えるteach + 人 + もの人にものを教える
send + 人 + もの人にものを送るbring + 人 + もの人にものを持ってくる
lend + 人 + もの人にものを貸すask + 人 + 質問人に質問をする
buy + 人 + もの人にものを買うmake + 人 + もの人にものを作る

例I gave him a book.（私は彼に本をあげました）

SVOOの書きかえ：下の動詞は、動詞＋人＋もの ＝ 動詞＋もの＋to［for］＋人

例I gave him a book. ＝ I gave a book to him.

前置詞使う動詞
togive / show / tell / teach / send / bring / lend
forbuy / make

SVOOの2つ目の目的語が語句・節になる形

形意味
show + 人 + how to + 動詞の原形人に〜のしかたを示す
tell + 人 + that + 主語 + 動詞人に〜ということを伝える
tell + 人 + 疑問詞 + 主語 + 動詞人に、何を［どこで…］〜するかを伝える

例Please show me how to use it.（使い方を私に示してください）

第5文型 SVOC　目的語と補語をとる動詞

形意味形意味
call + 目的語 + 補語〜を…と呼ぶmake + 目的語 + 補語〜を…にする
name + 目的語 + 補語〜を…と名づけるkeep + 目的語 + 補語〜を…のままにする

例We call him Ken.（私たちは彼をケンと呼びます）

完成した文関係完成した文関係

4. 進行形

be動詞 + 動詞のing形 の形。
am / is / are + 動詞のing形　（現在進行形）
（今）〜しているところだ
was / were + 動詞のing形　（過去進行形）
〜しているところだった

例I am studying English now.（私は今、英語を勉強しています）

be動詞 + -ing の形だけでは進行形と決まらない：My hobby is playing soccer. は「今している」ではなく動名詞（趣味は〜すること）。実際にその動作をしている途中かで見分ける。

否定文・疑問文

形作り方
主語 + be動詞 + not + 動詞のing形 + 〜.be動詞のうしろに not を置く
Be動詞 + 主語 + 動詞のing形 + 〜?be動詞を主語の前に出す

5. 未来

be going to か will があれば未来。どちらもうしろは動詞の原形。
be going to + 動詞の原形
〜するつもりだ／〜しそうだ
will + 動詞の原形
〜だろう／〜するつもりだ

例I am going to study tonight. / I will study tonight.

否定文・疑問文

形作り方
主語 + be動詞 + not + going to + 動詞の原形 + 〜.be動詞のうしろに not を置く
Be動詞 + 主語 + going to + 動詞の原形 + 〜?be動詞を主語の前に出す
主語 + will not + 動詞の原形 + 〜.will のうしろに not。短縮形は won't
Will + 主語 + 動詞の原形 + 〜?will を主語の前に出す

6. 命令文

主語がなく、いきなり動詞の原形で始まる文。
形訳
動詞の原形 + 〜.〜しなさい
Please + 動詞の原形 + 〜.
動詞の原形 + 〜, please.		〜してください
Don't + 動詞の原形 + 〜.〜してはいけません
Let's + 動詞の原形 + 〜.〜しましょう
Be + 〜.（be動詞の命令文）〜でいなさい

例Open the door, please.（ドアを開けてください）

文の先頭が疑問詞。Yes / No では答えない。

疑問文の作り方

条件形例文

選択疑問文：Do you want tea or coffee? のように選択肢を or で結ぶ。Yes / No ではなく、選んだ方で答える。

2語で使う疑問詞

形意味形意味

感嘆文（なんて〜だ！）

形例
How + 形容詞［副詞］ + 主語 + 動詞！How interesting (it is)!
What (a[an]) + 形容詞 + 名詞 + 主語 + 動詞！What a big tree (it is)!

8. There is［are］

文頭が There is / There are。この there は「そこに」と訳さない。
There is［are / was / were］ + 〜.
（…に）〜がある［あった］

例There is a book on the desk.（机の上に本が1冊あります）

否定文・疑問文

形作り方
There + be動詞 + not + 名詞 + 〜.
There + be動詞 + no + 名詞 + 〜.		be動詞のうしろに not、または名詞の前に no
Be動詞 + there + 名詞 + 〜?be動詞を there の前に出す
How many + 名詞の複数形 + are there + 〜?数をたずねる

9. 助動詞助動詞のように使う表現もふくむ

動詞の前に助動詞があり、そのうしろが動詞の原形。
主語 + 助動詞 + 動詞の原形 + 〜.

例I can swim.（私は泳ぐことができます）

助動詞意味
can〜することができる
must〜しなければならない／〜にちがいない
may〜してもよい／〜かもしれない
should〜するべきだ
will〜だろう／〜するつもりだ
shall〜しましょうか（Shall I / Shall we）
could〜することができた（can の過去形）
wouldwill の過去形・仮定法で使う。Would you 〜? で〜してくださいますか（ていねい）

助動詞のように使う表現（うしろは動詞の原形）

表現意味
have［has］to + 動詞の原形〜しなければならない
be able to + 動詞の原形〜することができる（can の書きかえ）

短縮形

短縮形もとの形短縮形もとの形
can'tcannotwon'twill not
mustn'tmust notshouldn'tshould not

助動詞は2つ並べられない。I will can swim. ではなく I will be able to swim. とする。must に過去形はないので、過去なら I had to study yesterday. のように表す。

否定文・疑問文

形作り方
主語 + 助動詞 + not + 動詞の原形 + 〜.助動詞のうしろに not を置く
助動詞 + 主語 + 動詞の原形 + 〜?主語の前に助動詞を出す

must と have to の否定文

形意味
must not + 動詞の原形〜してはいけない
don't［doesn't］have to + 動詞の原形〜しなくてよい

例You must not run here.（ここで走ってはいけません） / You do not have to come.（来る必要はありません）

助動詞を使った表現

形意味
Can［May］I + 動詞の原形 + 〜?〜してもいいですか
Can［Will］you + 動詞の原形 + 〜?〜してくれますか

11. 不定詞①3用法

to + 動詞の原形 のかたまり。
① 名詞的用法
〜すること

名詞と同様に、動詞の目的語・文の主語・補語になる。

例I want to play soccer.（私はサッカーをしたい）

② 形容詞的用法　名詞 + to + 動詞の原形
〜する（ための）／〜すべき

形容詞と同じ働きをし、名詞や代名詞をうしろから修飾する。

例I have homework to do.（私にはするべき宿題があります）

③ 副詞的用法
〜するために（動作の目的）／〜して（感情の原因・理由）

副詞と同じ働きをする。

例I went to the park to play soccer.（サッカーをするために公園へ行きました）

形意味

need to + 動詞の原形〜する必要がある
try to + 動詞の原形〜しようとする
begin［start］to + 動詞の原形〜し始める
something［anything］to + 動詞の原形何か〜するもの　※形容詞は something のうしろ
be glad［happy］to + 動詞の原形〜してうれしい
be sad［sorry］to + 動詞の原形〜して悲しい［残念だ］
be surprised to + 動詞の原形〜して驚く

12. 不定詞②重要な形

疑問詞 + to + 動詞の原形

形意味
how to + 動詞の原形〜のしかた、どう〜するか
what to + 動詞の原形何を〜したらよいか
where to + 動詞の原形どこで［へ／に］〜したらよいか
when to + 動詞の原形いつ〜したらよいか
which（+ 名詞）to + 動詞の原形どれを［どの…を］〜したらよいか

例I know how to use this computer.（私はこのコンピューターの使い方を知っています）

動詞 + 人 + to + 動詞の原形

形意味
tell + 人 + to + 動詞の原形（人）に〜するように言う
ask + 人 + to + 動詞の原形（人）に〜するように頼む
want + 人 + to + 動詞の原形（人）に〜してもらいたい

例My mother told me to clean my room.（母は私に部屋を掃除するように言いました）

make / let + 人 + 動詞の原形　／　help + 人 +（to）動詞の原形

形意味
make + 人 + 動詞の原形（人）に〜させる（強制）
let + 人 + 動詞の原形（人）に〜させる（許可）
help + 人 +（to）動詞の原形（人）が〜するのを手伝う

例My mother made me clean my room.（母は私に部屋を掃除させました）

make / let のうしろは必ず原形（to なし）。help だけは to をつけてもつけなくてもよい。

My mother made me to clean my room. → My mother made me clean my room.（make のうしろに to はつかない）

It is 〜 for … to の文

It is + 形容詞 + for + 人 + to + 動詞の原形.
（人）にとって〜するのは…です

例It is important for us to study English.（私たちにとって英語を勉強することは大切です）

よく使う形容詞：easy / difficult / important / necessary

13. 動名詞

動詞のing形 が名詞の働きをしている。形は進行形のing形と同じ。
動詞のing形
〜すること

文の中で主語・動詞の目的語・補語・前置詞の目的語になる。

例I enjoy playing soccer.（私はサッカーをすることを楽しみます）

不定詞（名詞的用法）との使い分け

どちらも「〜すること」を表すが、目的語になる場合は前の動詞ごとに形が決まる。まずは次の代表例を覚える。

とれる形動詞・表現基本の意味
to dowant / hope / decide / need / plan / learnうしろに to + 動詞の原形を置く
doingenjoy / finish / keep / practice / stopうしろに動詞のing形を置く
両方
意味はほぼ同じ		like / love / begin / start「〜すること」の意味では両方使える

覚えておきたい形

形意味
stop + 動詞のing形〜するのをやめる
forget to + 動詞の原形〜するのを忘れる
remember to + 動詞の原形忘れずに〜する

例I stopped playing soccer.（サッカーをするのをやめました）

前置詞のうしろに動詞を置くなら動名詞（to 不定詞は使えない）

形意味
Thank you for 〜ing.〜してくれてありがとう

14. 比較①原級・比較級・最上級

as 〜 as なら原級、than があれば比較級、the -est / the most なら最上級。
as + 原級 + as + 〜
…と同じくらい〜
比較級 + than + 〜
…よりも〜
the + 最上級 + in［of］ + 〜
…の中で一番〜

例Ken is as tall as Tom. / Ken is taller than Tom. / Ken is the tallest in his class.

範囲が場所・集団なら in、数や構成員を示す語句なら of。

比較級・最上級の形

条件形
ふつうの語語尾に er, est（old – older – oldest）
つづりの長い語前に more, most（beautiful – more beautiful – most beautiful）
不規則変化good / well – better – best
bad – worse – worst
many / much – more – most
little（量）– less – least

Ken is more taller than Tom. → Ken is taller than Tom. / This book is gooder than that one. → This book is better than that one.

15. 比較②重要な形

形意味
like A better than BBよりもAのほうが好きだ
like A (the) best in［of］ + 〜…の中でAが一番好きだ
Which［Who］ + 比較級 + 〜, A or B?AとBではどちらのほうが〜ですか
What［Who / Which］ + 最上級 + 〜 + in［of］ + …?…の中で何［だれ／どれ］が一番〜ですか
one of the + 最上級 + 複数名詞 + 〜最も〜の中の1つ
not as + 原級 + as + 〜…ほど〜ではない
as + 原級 + as possibleできるだけ〜

書きかえ：A is not as tall as B. ＝ B is taller than A.（主語が入れかわる）

16. 接続詞

対等につなぐ

語意味語意味
and〜と…but〜しかし…
or〜かまたは…so〜それで…

文をつなぐ（うしろは 主語＋動詞）

語意味
when + 主語 + 動詞〜（する［した］）とき
because + 主語 + 動詞〜なので
if + 主語 + 動詞もし〜ならば
before + 主語 + 動詞〜する前に
after + 主語 + 動詞〜したあとに

例I stayed home because it was raining.（雨が降っていたので家にいました）

時・条件を表す接続詞（when / if / before / after / until / as soon as など）の中は、未来のことでも現在形で書く。

that

形意味
動詞 + (that) + 主語 + 動詞〜ということ
know / think / hope / feel / say / understand

例I think that English is important.（私は英語が大切だと思います）

接続詞の that は省略できる。

そのほかの重要な形

形意味
both A and BAとBの両方とも
so + 形容詞・副詞 + that + 主語 + 動詞とても…なので〜
as soon as + 主語 + 動詞〜するとすぐに

例Ken is so tired that he can't walk. ＝ Ken is too tired to walk.

17. 分詞

現在分詞＝進行形で使う動詞のing形と同じ。過去分詞＝規則動詞は過去形と同じ形、不規則動詞は固有の形。

現在分詞（〜している…）

形使うとき
名詞 + 現在分詞 + 語句他の語句といっしょに用いるとき → 前の名詞を修飾
現在分詞 + 名詞単独で用いるとき → うしろの名詞を修飾

例The boy playing soccer is Ken.（サッカーをしている少年はケンです）

過去分詞（〜される［された］…）

形使うとき
名詞 + 過去分詞 + 語句他の語句といっしょに用いるとき → 前の名詞を修飾
過去分詞 + 名詞単独で用いるとき → うしろの名詞を修飾

例This is a picture taken by my father.（これは父が撮った写真です）

2語以上なら名詞のうしろ、1語だけなら名詞の前。これが現在分詞・過去分詞に共通のルール。

18. 現在完了①継続

have［has］+ 過去分詞 の形。よく使う目印：for / since があれば継続。
have［has］ + 過去分詞
ずっと〜している［〜してきた］

例I have lived here for three years.（私は3年間ここに住んでいます）

形意味
for + 期間を表す語句〜の間
since + 起点を表す語句〜以来、〜から（今まで）

否定文・疑問文

形意味
主語 + have［has］not + 過去分詞 + 〜.ずっと〜していません
Have［Has］ + 主語 + 過去分詞 + 〜?ずっと〜していますか
How long have［has］ + 主語 + 過去分詞 + 〜?どのくらい〜していますか

I have played soccer yesterday. → I played soccer yesterday.（過去の一点を表す語といっしょなら過去形）

動作がずっと続いているとき

have［has］been + 動詞のing形
ずっと〜し続けている

例I have been studying English for two hours.（私は2時間ずっと英語を勉強しています）

know / be / like など状態を表す動詞は基本的に have + 過去分詞。study / run / rain / live など動作が続くことを表す動詞は have + 過去分詞 でもよいが、続けていることを強調するときは have been + ing形。

Have［Has］ + 主語 + 過去分詞 + 〜(yet)?もう〜してしまいましたか

20. 受動態

be動詞 + 過去分詞 の形。by 〜 があればほぼ確定。
be動詞 + 過去分詞（+ by + 行為者）
（…によって）〜される、〜された

例English is spoken in many countries.（英語は多くの国で話されています）

be動詞は主語と時制で使い分ける ── is, am, are（現在）／was, were（過去）。

時制・助動詞による形

形時形時・意味

形

21. 関係代名詞

名詞のうしろが who / which / that、またはいきなり「主語＋動詞」。

主格（うしろが動詞）

形意味
人 + who + 動詞 + 〜〜する（人）
もの + which + 動詞 + 〜〜する（もの）
人［もの］ + that + 動詞 + 〜〜する（人［もの］）

例I know a boy who speaks English.（私は英語を話す少年を知っています）

目的格（うしろが主語＋動詞・省略できる）

形意味
人［もの］ + that + 主語 + 動詞 + 〜主語が〜する（人［もの］）
もの + which + 主語 + 動詞 + 〜主語が〜する（もの）
人［もの］ + 主語 + 動詞 + 〜主語が〜する（人［もの］）※接触節（関係代名詞の省略）

例This is the book I bought yesterday.（これは私が昨日買った本です）

主格は省略できない。目的格は省略できる。見分けは関係代名詞のうしろを見るだけ ── いきなり動詞なら主格、主語＋動詞なら目的格。

24. 仮定法

現実とちがうことを言う形。If の中の動詞は過去形。

ふつうの条件（〜ならば）を表す if は現在形のまま（第16章）。現実とちがうことを仮定するときだけ、if の中を過去形にする。

If + 主語 + 過去形 〜, 主語 + would［could］ + 動詞の原形 ….
もし〜なら…なのに（実際はそうではない）
形意味
If I were you, I would study harder.もし私があなたなら、もっと一生懸命勉強するのに
If you had a million yen, what would you buy?もし100万円持っていたら、何を買いますか

If の中の be動詞 は、基本形として主語にかかわらず were を覚える。

I wish + 主語 + 過去形 〜.
〜だったらいいのに（実際はそうではない）
I wish I knew the answer.（答えを知っていたらいいのに）

If I am you, I will help you. → If I were you, I would help you.（現実とちがう仮定では過去形とwouldを使う）
